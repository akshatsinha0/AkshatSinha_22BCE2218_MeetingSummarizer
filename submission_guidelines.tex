% Project Overview
\section*{Project Overview}

\textbf{Meeting Summarizer} is a comprehensive AI-powered application that transcribes meeting audio files and generates intelligent summaries with key decisions and action items. The project runs entirely locally with zero-cost operation, leveraging open-source technologies.

\subsection*{Key Highlights}

\begin{itemize}[leftmargin=*, itemsep=6pt]
    \item \textbf{100\% Local \& Free:} No cloud dependencies, runs completely offline
    \item \textbf{Real-time Transcription:} Live audio streaming with WebSocket support
    \item \textbf{Speaker Diarization:} Automatic speaker identification and labeling
    \item \textbf{AI Summarization:} LLM-powered summaries with key decisions and action items
    \item \textbf{Modern UI:} Next.js frontend with dark/light themes and accessibility features
    \item \textbf{Advanced Features:} Transcript editing, bookmarks, compliance checking, calendar integration
\end{itemize}

% Tech Stack
\section*{Technology Stack}

\subsection*{Backend}
\begin{itemize}[leftmargin=*, itemsep=4pt]
    \item \textbf{Framework:} FastAPI (Python)
    \item \textbf{ASR:} OpenAI Whisper (faster-whisper, large-v3-turbo model)
    \item \textbf{LLM:} Ollama (local LLM - gemma3:4b)
    \item \textbf{Diarization:} pyannote.audio
    \item \textbf{Database:} SQLite
    \item \textbf{Performance:} Rust extensions (PyO3) for audio processing
\end{itemize}

\subsection*{Frontend}
\begin{itemize}[leftmargin=*, itemsep=4pt]
    \item \textbf{Framework:} Next.js 15.5.4 (App Router)
    \item \textbf{Language:} TypeScript
    \item \textbf{Styling:} Inline CSS with theme support
    \item \textbf{Real-time:} WebSocket for live transcription
\end{itemize}

\section*{Implemented Features}

\subsection*{Core Features}

% Setup Instructions
\section*{Setup \& Installation}

\subsection*{Prerequisites}
\begin{itemize}[leftmargin=*, itemsep=4pt]
    \item Node.js (for frontend)
    \item Python 3.11+ (for backend)
    \item FFmpeg (for audio processing)
    \item Ollama (for local LLM)
    \item Rust (for audio extensions)
\end{itemize}

\subsection*{Installation Steps}
\begin{enumerate}[leftmargin=*, itemsep=6pt]
    \item Clone the repository
    \item Create Python virtual environment: \texttt{python -m venv .venv}
    \item Install backend dependencies: \texttt{pip install -r backend/requirements.txt}
    \item Build Rust extensions: \texttt{maturin develop}
    \item Install frontend dependencies: \texttt{cd frontend \&\& npm install}
    \item Copy \texttt{.env.example} to \texttt{.env} and configure
    \item Start backend: \texttt{./backend/run\_dev.ps1}
    \item Start frontend: \texttt{cd frontend \&\& npm run dev}
\end{enumerate}
